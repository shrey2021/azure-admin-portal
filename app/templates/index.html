Azure Connection & Environment

Active Mode:

Toggle between simulated Demo data and live Azure Resource Manager.

Connection Test:

Verify network and authentication access to Azure API endpoints.

How to connect to your real Azure Subscription:

  1. Open PowerShell or Azure Cloud Shell and run: 
    az ad sp create-for-rbac --name "AzureAdminPortal-SP" --role Contributor --scopes /subscriptions/YOUR_SUBSCRIPTION_ID
  2. Copy .env.example to .env in your project root: 
    cp .env.example .env
  3. Fill in your credentials: 
    DEMO_MODE=false
AZURE_TENANT_ID=<appOwnerTenantId>
AZURE_CLIENT_ID=<appId>
AZURE_CLIENT_SECRET=<password>
AZURE_SUBSCRIPTION_ID=<subscription_id>
  4. Restart the portal or click Test Connection.
